Open Source

rudzio
async test framework for Rust

crates.io | GitHub | docs.rs

I have discovered that long-running agent-driven work depends on test design, and that using cargo test in monolithic codebases is frustrating. Rudzio runs tests from multiple crates in a single process with non-blocking interactive terminal output and each runtime on its own thread, handling panics, SIGTERM/SIGINT, suite setup errors, timeouts, cancellation and teardown. It organises tests into Suites, which might define complex setup and teardown logic guaranteed to be called. Resource ownership is a lifetime hierarchy enforced by the compiler: 'runtime: 'suite_context: 'test_context. This allows writing tests that, for example, create a Podman container, always perform cleanup even when a panic appears, create a connection pool, borrow a connection per test. It is possible to plug in any asynchronous runtime and Rudzio is completely runtime agnostic (currently supports tokio, compio, async-std, smol, monoio, embassy and futures-executor).

Technologies: 🦀 Rust, proc macros, cargo internals, async runtimes, threading, panic unwinding, cancellation.
